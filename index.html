ABOUT GRID

Think of GRID as an intelligent digital security guard for your entire building. Designed for building owners, housing societies and busy office spaces, GRID keeps a continuous eye on your building’s electrical health to catch tiny maintenance hiccups before they turn into expensive disasters. It works by listening to electrical signals in real time instantly stepping in during short circuits to cut off power before sparks can start dangerous electrical fires, while automatically smoothing out dangerous voltage spikes to keep your valuable appliances running safely for years. Beyond power management, GRID continuously scans your facility using HVAC air pressure and humidity sensors to optimize climate control, combined with high precision water pressure sensors to instantly flag hidden pipe leaks before flooding causes structural damage.

Our Features

Real-time Telemetry
Sub-second sensor telemetry syncing directly via WebSockets from edge devices to live web applications.
Inventory Control
Automated component tracking, dispatch logging, and dynamic inventory sync to reduce operational overhead.
Threshold Alerts
Instant monitoring for critical temperature, humidity, and liquid level breaches with continuous diagnostic logs.
Cloud Infrastructure
Monolithic Express architecture hosted on Render for seamless HTTP REST endpoints and low-latency websocket routing.

Frequently Asked Questions

Everything you need to know about the GRID telemetry system

How does GRID connect with physical hardware?
+
GRID interfaces directly with microcontrollers and single-board computers including ESP8266, ESP32, STM32, and Raspberry Pi via HTTP REST endpoints and WebSockets, relaying real-time sensor payloads effortlessly.
What all sensors can it support in the future?
+
We are currently demoing water level indicators and HVAC humidity sensors, but GRID is designed to support virtually any sensor architecture running on ARM64 platforms.
Is the backend scalable for large inventory networks?
+
Yes, built on Node.js Express hosted on Render cloud infrastructure, GRID handles fast concurrent websocket connections effortlessly.
How can I test the system before deploying hardware?
+
You can send test JSON payloads via tools like Postman directly to the /api/telemetry endpoint to watch the dashboard update live.
